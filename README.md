# Verve

> Strava + Hevy Hybrid Performance Fitness Suite

Verve is an all-in-one athletic tracking system combining **live GPS route tracking, pace splits, and elevation metrics** (Strava-grade) with **comprehensive gym workout logging, muscle heatmaps, and weekly split management** (Hevy-grade).

## Features
- **GPS Running Engine**: Real-time pace, live split markers, route plotting, and elevation gain calculation.
- **Workout Split Planner**: Customizable Push/Pull/Legs and Upper/Lower routine templates.
- **Set Logger**: Warmup (`W`), Normal (`N`), Drop (`D`), and Failure (`F`) tracking with automatic rest countdowns.
- **Visual Exercise Library**: 60+ exercises with target muscle activation previews.
- **Combined Feed & Analytics**: Integrated dashboard for running mileage, total volume tonnage, and muscle volume distribution.
